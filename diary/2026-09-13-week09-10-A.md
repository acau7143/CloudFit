## 왜 이 기술/방법을 선택했는가
| 항목 | 선택한 것 | 대안 | 선택 이유 |
|------|-----------|------|-----------|
| 미사용 리소스 판정 기준 | `describe_volumes(status=available)` + `describe_addresses()`의 `AssociationId` 없음 | 실제 볼륨 detach 재현 테스트 | IAM 역할(`CloudWatchAgentRole`)이 최소 권한 원칙상 `CreateVolume` 등 생성 계열 차단, 가상 데이터로 파이프라인만 검증 |
| 미사용 리소스 저장 경로 | 중앙 서버(FastAPI) API 경유 | DB 직접 접속(asyncpg) | 실제 레포가 이미 `aws_exporter.py`부터 FastAPI 경유 패턴으로 통일돼 있어 그 컨벤션을 따름 |
| RI 판정 기준 | 최근 7일 수집 샘플 수 / 기대 샘플 수(2016) 비율 | CloudWatch 가동 로그 직접 조회 | 기존 5분 주기 수집 데이터로 근사 가능, 추가 API 호출 불필요 |
| 월 예산값 | $50 (계획서 예시값, 잠정) | 팀 협의 후 확정값 | 시간 제약상 잠정값으로 진행, decisions에 미확정 상태 명시 |
| EBS 볼륨 크기 | 30GB | 20GB | 비용 차이 미미(월 약 1,000원), 향후 라이브러리 추가에도 여유 두기 위해 |
